# Tooling

Nguyen.go ships four CLI utilities for everyday development beyond
`dev`/`build`/`start`: `doctor` for environment diagnostics, `vet` for
static analysis, `generate` for codegen, and `dist` for reproducible
cross-compiled releases.

## nguyen doctor

Diagnoses the local toolchain and project layout before you run
`dev` or `build`.

```bash
nguyen doctor
```

Sample output:

```
  ⬡ Nguyen.go — Doctor
  Framework v1.1.0

  ✓  Go runtime                    go1.25.0 on linux/amd64
  ✓  TinyGo                        tinygo version 0.41.1
  ●  Tailwind binary               not present (optional)
       ↳ Run 'nguyen create my-app --tailwind' to scaffold
  ✓  pages/ directory              pages (8 file(s))
  ✓  public/ directory             public (3 file(s))
  ✓  styles/ directory             styles (2 file(s))
  ✓  config/nguyen.config.yml      config/nguyen.config.yml
  ✓  Git repository                initialised

  6 passed  1 info
```

Doctor exits non-zero only when a hard prerequisite (Go version) is
unmet, so it is safe to wire into CI as a fast pre-flight check.

## nguyen vet

Runs static analysis on every `.gox` file. Errors fail vet (exit 1).
Warnings do not unless you pass `--strict`.

```bash
nguyen vet                  # default rules, warnings non-fatal
nguyen vet --strict         # fail on warnings (CI gating)
nguyen vet --pages src/pages
```

Built-in rules:

| Rule | Severity | What it catches |
|---|---|---|
| `context-first-param` | warning | `Load`, `Action`, `Stream`, `Handle`, `GET`/`POST`/... must take `context.Context` first |
| `no-time-sleep` | warning | `time.Sleep` ignores ctx — suggests `select { case <-time.After: case <-ctx.Done(): }` |
| `goroutine-cancellation` | warning | `go func() { ... }` that never references `ctx` may outlive its request |
| `no-hardcoded-secrets` | error | string literals matching API key / password / token patterns |
| `no-fmt-print` | warning | `fmt.Println` / `fmt.Printf` bypass the structured logger |
| `event-handler-exists` | error | `@click="foo()"` requires `func foo()` in frontmatter |

These rules are the seed of the future Effect Wall — a compile-time
classifier that will infer which functions touch DB / network / DOM and
fail builds when an effect crosses a server/client/edge boundary.

## nguyen generate

Code generation utilities. Generated files use the `.gen.go` suffix and
are deterministic — running generate twice produces byte-identical
output.

### nguyen generate routes

Reads `pages/*.gox`, sorts routes deterministically, and emits one
function per route. Static routes return constants; dynamic routes
take typed parameters.

```bash
nguyen generate routes \
    --pages pages \
    --out routes/routes.gen.go \
    --package routes
```

Generated file (excerpt):

```go
// Code generated by nguyen generate routes. DO NOT EDIT.
package routes

var All = []string{
    "/",
    "/about",
    "/blog",
    "/blog/:slug",
}

func Index() string  { return "/" }
func About() string  { return "/about" }
func Blog() string   { return "/blog" }
func BlogBySlug(slug string) string { return join("/", "blog", slug) }
```

Use it to make routing typo-proof:

```go
<a href={routes.BlogBySlug(post.Slug)}>{post.Title}</a>
```

A typo (`routes.BlogBySlugg`) becomes a compile error rather than a
404 at runtime.

Commit the generated file. CI can verify it is up to date by running
`nguyen generate routes` and checking `git diff` is empty.

## nguyen dist

Cross-compiles reproducible single-file binaries for one or more target
platforms. The same input source tree always produces byte-identical
output, so binary hashes can be pinned in supply-chain attestations.

```bash
nguyen dist                                       # current platform
nguyen dist --targets linux/amd64,linux/arm64    # multi-target
nguyen dist --reproducible=false                  # disable trimpath/buildid
```

Default flags: `--reproducible` (on), `--main ./cmd/server`, `--name app`,
`--output dist`, `--targets <current GOOS/GOARCH>`.

Output layout:

```
dist/
├── linux-amd64/app
├── linux-arm64/app
└── darwin-arm64/app
```

When `--reproducible` is enabled, dist sets:

- `-trimpath` — strips host paths from binaries
- `-buildvcs=false` — omits VCS metadata
- `-ldflags "-s -w -buildid="` — strips symbols, debug, and build ID
- `CGO_ENABLED=0` — fully static link
- `SOURCE_DATE_EPOCH=0` — for any link-time tools that read it

Verify reproducibility:

```bash
sha256sum dist/*/app
# build again from a clean checkout, compare hashes
```

This is how supply-chain verification works for Bazel / Nix builds, and
it is how Nguyen.go binaries are intended to be shipped.

### Air-gapped deploys

A reproducible Nguyen.go binary embeds its assets via `embed.FS` and
links statically — `scp app server:/srv && ./app` is a complete
deployment with no Docker, no Node, no apt-get.
